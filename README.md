# عيادة نور لطب الأسنان — مشروع متكامل ومربوط بـ Firebase 🦷✨

موقع متكامل واحترافي لعيادة طب أسنان باللغة العربية (RTL) مبني بأحدث معايير الويب باستخدام HTML5 و CSS3 و Vanilla JavaScript ومربوط كلياً بقاعدة بيانات **Google Firebase** (Firestore & Analytics).

## 🔥 إعدادات Firebase المربوطة بالمشروع

المشروع مهيأ ومربوط بالكامل مع مشروع Firebase الخاص بك:
- **Project ID:** `dental-6a394`
- **Auth Domain:** `dental-6a394.firebaseapp.com`
- **Firestore Collection:** `appointments` (يتم تخزين بيانات كل حجز فيها تلقائياً)
- **Analytics:** مهيأ لتسجيل أحداث الحجز وزيارات الصفحات.

### 🛡️ قواعد أمان Firestore (Firestore Security Rules):
للسماح للمرضى بحجز المواعيد وللإدارة بمشاهدتها، تأكد من ضبط قواعد Firestore في لوحة تحكم Firebase (`Firestore Database` -> `Rules`) كالتالي:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /appointments/{appointmentId} {
      // السماح بالقراءة والكتابة للحجوزات
      allow read, write: if true;
    }
  }
}
```

> **ملاحظة ذكية:** في حال كانت القواعد مغلقة أو حدث انقطاع في الاتصال، يحتوي النظام على آلية نسخ احتياطي محلية (LocalStorage Cache) لضمان عدم ضياع أي بيانات حجز نهائياً.

## 🚀 كيفية تشغيل المشروع

1. افتح أي صفحة من صفحات المشروع (`index.html`, `booking.html`, `admin.html`) في أي متصفح حديث (Chrome, Edge, Safari, Firefox).
2. أو قم بتشغيل خادم محلي خفيف مثل:
   - عبر إضافة **Live Server** في VS Code.
   - أو عبر بايثون: `python -m http.server 8000` ثم فتح `http://localhost:8000`

## 🌟 المميزات المدمجة في المشروع

1. **تصميم عربي حديث (RTL First):**
   - خطوط عربية أنيقة من Google Fonts (`Cairo` للعناوين والأزرار، و `Tajawal` للنصوص الطبية).
   - لوحة ألوان طبية هادئة مستوحاة من الهوية البصرية للعيادات الحديثة: Clinical Teal (`#0E7C7B`) و Soft Mint (`#E6F4F1`) مع Coral (`#EA580C`) لأزرار الحجز الأساسية.

2. **ربط كامل وتلقائي بين الصفحات:**
   - التنقل السلس بين الصفحة الرئيسية، صفحة الخدمات، صفحة الأطباء، وصفحة الحجز.
   - عند الضغط على "احجز مع د. ليلى" أو "احجز خدمة التقويم"، يتم نقلك لصفحة الحجز وتعبئة الخدمة أو الطبيب تلقائياً!

3. **لوحة تحكم إدارة واستقبال فورية (`admin.html`):**
   - متابعة الحجوزات القادمة في الوقت الفعلي (Real-time Sync عبر `onSnapshot`).
   - إحصائيات فورية (إجمالي الحجوزات، قيد الانتظار، المؤكدة).
   - فلترة وتصفح المواعيد حسب الحالة والبحث بالاسم أو رقم الهاتف.
   - إمكانية تأكيد الموعد، أو إلغائه، أو حذفه بنقرة زر واحدة.
